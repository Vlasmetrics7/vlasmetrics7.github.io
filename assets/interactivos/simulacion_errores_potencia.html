Simulación: errores tipo I y tipo II, y potencia

Prueba Z para la media de una población normal con σ conocida: H₀: μ = μ₀ = 0 contra H₁: μ > 0 (una cola) o H₁: μ ≠ 0 (dos colas). El estadístico es Z = √n (X̄ − μ₀)/σ. Se rechaza H₀ cuando Z cae más allá del umbral (valor crítico). Las curvas muestran cómo se distribuye Z si H₀ es cierta (azul) y si lo es la media μ₁ (naranja), para el tamaño de muestra elegido.

  • Mueve el umbral: al hacerlo más estricto, α baja pero β sube (Observación 6.2.3 del capítulo).
  • Aumenta n: las dos curvas se separan y bajan α y β a la vez.
  • Acerca μ₁ a 0: con el mismo α, β crece (Figura 6.2).
  • Simula muestras (abajo): con H₀ cierta, la fracción de rechazos ronda α; con H₁ cierta, ronda la potencia.
